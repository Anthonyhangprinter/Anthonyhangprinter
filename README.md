# Anthony Romanelli

Engineering student at UNSW Sydney working at the intersection of **AI agents and digital fabrication** — building systems where language models design, verify, and manufacture real parts.

## Focus

- **Text-to-CAD agents** — LLM-driven parametric CAD generation with deterministic geometry verification
- **Local-first AI infrastructure** — serving and routing open-weight models on consumer hardware
- **Digital fabrication** — 3D printing, CNC, and laser workflows from generated geometry
- **Benchmark-driven development** — every capability A/B-measured; negative results documented

## Selected work

**[maker-agent](https://github.com/Anthonyhangprinter/maker-agent)** — a fully-local text-to-CAD agent. Natural-language spec → build123d code → measured geometry → deterministic verification gate → STEP/STL/DXF/G-code. Includes a measured learning loop (few-shot retrieval, best-of-N sampling, SFT-pair harvesting) and a documented QLoRA fine-tuning campaign.

**[Firmware-Solution](https://github.com/Anthonyhangprinter/Firmware-Solution)** · **[DAQ-Technical-Assessment](https://github.com/Anthonyhangprinter/DAQ-Technical-Assessment)** — embedded C firmware and TypeScript data-acquisition work.

**[hangprinter](https://github.com/Anthonyhangprinter/hangprinter)** — RepRap cable-driven 3D printer.
